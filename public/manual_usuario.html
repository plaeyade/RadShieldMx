RadShield-MX es una plataforma integral de codigo abierto para el diseno, calculo y optimizacion de blindajes radiologicos en instalaciones medicas e industriales. Desarrollada en Mexico, cumple con la normativa de la Comision Nacional de Seguridad Nuclear y Salvaguardias (CNSNS) asi como con estandares internacionales.

5. Fundamentos de Blindaje Radiologico

5.1. Formulas NCRP 147 (2004) y NCRP 151 (2005)

RadShield-MX implementa las formulas oficiales de la National Council on Radiation Protection and Measurements para el calculo de blindajes en instalaciones de radiologia y radioterapia.

5.1.1. Barrera primaria — NCRP 147 Eq. 4.1 / NCRP 151 Eq. B.1

B = (P * d^2) / (W * U * T)

Donde:
  B  = Factor de transmision requerido (adimensional)
  P  = Meta de dosis semanal (mSv/semana)
       P_controlado  = 0.1 mSv/sem (5 mSv/ano / 50 semanas)
       P_publico     = 0.02 mSv/sem (1 mSv/ano / 50 semanas)
  d  = Distancia fuente-barrera (metros)
  W  = Carga de trabajo semanal
       Diagnostico: mA*min/semana
       Terapia: Gy/semana
  U  = Factor de uso (fraccion del tiempo que el haz apunta a la barrera)
       U_primaria    = 1.0 (haz directo)
       U_secuencia   = 1/4 a 1/16 (segun configuracion)
  T  = Factor de ocupacion del area protegida (NCRP 147 Table A.1)
       T = 1.0 (control room), T = 1/5 (corridor), T = 1/20 (waiting)

5.1.2. Espesor de blindaje — Metodo TVL

n = -log10(B)           = numero de capas valor diez (TVL) requeridas
t = n * TVL(mm)          = espesor total del material de blindaje

Donde TVL (Tenth-Value Layer) depende del material y la energia:
  Concreto 2.35 g/cm3 a 6 MV:  TVL ≈ 370 mm
  Plomo 11.34 g/cm3 a 6 MV:    TVL ≈ 53 mm
  Acero 7.87 g/cm3 a 6 MV:     TVL ≈ 100 mm
  Concreto a 120 kVp (DX):     TVL ≈ 21 mm
  Plomo a 120 kVp (DX):        TVL ≈ 0.3 mm

5.1.3. Barrera secundaria — Scatter + Leakage

Barrera secundaria = max(B_scatter, B_leakage)

Scatter (NCRP 147 Sec. 4.4):
  B_s = (P * d_sec^2 * d_scat^2) / (a * W * T * F * (400/d_scat^2))
  
  Donde:
    a  = fraccion de scatter (NCRP 147 Table A.3, 0.0015 a 0.0027)
    d_sec  = distancia fuente-paciente-barrera (m)
    d_scat = distancia fuente-paciente (m)
    F  = area del campo (cm2)

Leakage (NCRP 151 Sec. B.3):
  B_L = (P * d^2) / (W_L * T)
  
  Donde W_L = carga de trabajo de leakage (tipicamente 0.1% del primario)

5.1.4. Blindaje neutronico — NCRP 151 Sec. B.4

n = log10(H_w / P)
t = n * TVL_neutron (cm)

Donde:
  H_w = dosis semanal de neutrones sin blindaje (mSv/sem)
  P   = meta de dosis (0.02 mSv/sem para publico)
  TVL_neutron depende del material:
    Concreto estandar:     TVL = 45 cm (McGinley 1998)
    Polietileno (PE):      TVL = 5.0 cm
    Polietileno borado:    TVL = 3.5 cm
    Agua:                  TVL = 3.8 cm
    Tierra compactada:     TVL = 55 cm

6. Simulacion Monte Carlo

6.1. Motor MC Nativo (TypeScript)

RadShield-MX incluye un motor Monte Carlo de transporte de fotones implementado completamente en TypeScript, ejecutable en el navegador sin backend.

Procesos fisicos implementados:
  1. Efecto fotoelectrico (dominante < 50 keV)
  2. Dispersion Compton (Klein-Nishina, 50 keV - 10 MeV)
  3. Dispersion Rayleigh (coherente, < 100 keV)
  4. Produccion de pares (> 1.022 MeV)

Aceleracion espacial:
  - KD-tree para interseccion de rayos O(log n)
  - Morton codes para hashing espacial (50x mas rapido que busqueda lineal)
  - WebWorkers para calculos asincronos (no bloquea UI)

Scoring:
  - H*(10) equivalente de dosis ambiental (ICRP 74)
  - Espacial: mapa de dosis 2D sobre el canvas
  - Espectral: histograma de energia por barrera

Materiales soportados (7):
  Agua (ICRU 44), Hueso compacto, Tejido blando (ICRU 44),
  Plomo (Pb), Acero (Fe), Concreto (2.35 g/cm3), Tungsteno (W)

7. Machine Learning para Blindaje

7.1. Arquitectura ANN [6-64-32-16-1] — v101

El modelo de red neuronal artificial predice el espesor optimo de blindaje a partir de 6 parametros de entrada.

Arquitectura (validada con literatura 2024-2026):
  Input layer:  6 neuronas  [E_MeV, A_GBq, d_m, T_occ, U_use, material_Zeff]
  Hidden 1:     64 neuronas, activacion ReLU
  Hidden 2:     32 neuronas, activacion ReLU
  Hidden 3:     16 neuronas, activacion ReLU
  Output:       1 neurona   [espesor_mm]

Training:
  Optimizador: Levenberg-Marquardt (papers) / Adam (PyTorch)
  Loss: MSE (Mean Squared Error)
  Datos: Tablas NCRP 147/151 + simulaciones Monte Carlo
  Metricas: MAE < 1%, R^2 > 0.97

Export: torch.onnx.export() / skl2onnx.convert_sklearn()
Runtime: onnxruntime-node (5x mas rapido que PyTorch nativo)

Referencias:
  - Ickecan et al. (2026). IntechOpen. DOI:10.5772/intechopen.1015114 (R^2=0.9885)
  - PMC12686668 (2025). ANN for Gamma Shielding. Error < 1% vs MCNP.

7.2. Optimizacion Multi-Objetivo — v105

El optimizador resuelve el problema de minimizar simultaneamente costo, peso y espacio ocupado, sujeto a la restriccion de dosis.

Funcion objetivo (weighted sum method):
  min f(x) = w1 * f_costo(x) + w2 * f_peso(x) + w3 * f_espacio(x)
  sujeto a: dosis(x) <= P * 1.05

  Donde x = (material, espesor) y w1 + w2 + w3 = 1.0

Normalizacion:
  f_costo  = costo_USD / 50000    (maximo referencia)
  f_peso   = peso_kg / 50000      (maximo referencia)
  f_espacio = espesor_mm / 1000   (maximo referencia)

Costos USD/kg (2024):
  Pb: $2.5/kg, Concrete: $0.15/kg, Steel: $1.2/kg,
  Gypsum: $0.4/kg, PE: $3.5/kg, BPE: $8.0/kg, W: $45.0/kg

  3. Categoria II (ETIQUETA AMARILLA): 5 uSv/h < dosis superficie < 500 uSv/h y dosis a 1m < 10 mSv/h. Ej: Mo-99/Tc-99m generadores, Ir-192 braquiterapia.

  5. El sistema resalta la categoria recomendada segun los datos ingresados.

  2. Embalaje tipo A, B(U), B(M) segun actividad.
  3. Pruebas de resistencia mecanica, termica, penetracion de agua.
  4. Etiquetado correcto con numero UN y TI.

  3. Co-60 (Gamma=0.305 uSv*m2/GBq*h), Ir-192 (0.13), Cs-137 (0.077), I-131 (0.048), Tc-99m (0.014), F-18 (0.14), Mo-99 (0.084), Ra-226 (0.195).

17. Geant4 Monte Carlo Validacion — v103

Herramienta de validacion que compara los calculos NCRP contra simulaciones Monte Carlo (gold standard) con tres niveles de precision.

  1. Haga clic en MC (icono Atom, color verde) en el toolbar o sidebar.
  2. Ingrese los parametros del escenario:
    • Energia (MeV): 0.01 a 10
    • Actividad (GBq): carga de trabajo
    • Distancia (m): fuente-barrera
    • Espesor (mm): del blindaje actual
    • Material: seleccione de la lista
  4. Seleccione el nivel de precision:
    • Nivel 1 (10^5 historias): Rapido, ~2 segundos, precision ~5%
    • Nivel 2 (10^6 historias): Estandar, ~20 segundos, precision ~1.5%
    • Nivel 3 (10^7 historias): Preciso, ~200 segundos, precision ~0.5%
  5. Haga clic en Ejecutar Geant4 MC.
  6. Barra de progreso muestra el avance de la simulacion.
  7. Resultados:
    • Dosis MC: mSv/semana simulada
    • Transmision B: factor de transmision Monte Carlo
    • Diferencia %: vs calculo NCRP
    • PASS/FAIL: Verde si diferencia < 5%, Rojo si > 5%
    • HVL/TVL: automaticos por material y energia
  8. En v103, la simulacion es un placeholder cliente con incertidumbre estadistica simulada.
  9. La implementacion completa con Docker Geant4/GATE esta planificada para v111+.
  10. Referencia: G4-Med (2020) Med Phys 48(1):19-56, NCRP 151 Sec. B.1.

18. Blindaje de Neutrones — v109

Calculadora dedicada para blindaje de neutrones en instalaciones de radioterapia con energias > 10 MV, conforme NCRP 151 Table B.7.

  1. Haga clic en Neu (icono Atom, color cyan) en el toolbar o sidebar.
  2. Seleccione la energia del acelerador (MV):
    • 10 MV: 0.5 Gy/h a 1m — Neutrones moderados
    • 15 MV: 1.0 Gy/h — Neutrones significativos
    • 18 MV: 2.0 Gy/h — Alta produccion neutronica
    • 20 MV: 3.5 Gy/h — Neutrones dominantes
    • 25 MV: 6.0 Gy/h — Blindaje neutronico obligatorio
  3. Ingrese distancia (m) desde el isocentro al punto de proteccion.
  4. Seleccione material de blindaje:
    • Concreto estandar: TVL = 45 cm
    • Polietileno (PE): TVL = 5.0 cm — Moderacion rapida
    • Polietileno borado 5% (BPE): TVL = 3.5 cm — Moderacion + captura
    • Acero + BPE (doble capa): TVL = 4.0 cm — Estructural
    • Agua: TVL = 3.8 cm — Economica
    • Tierra compactada: TVL = 55 cm — Exterior
  5. Ingrese carga de trabajo (Gy/semana).
  6. Haga clic en Calcular.
  7. Resultados:
    • Dosis sin blindaje (mSv/sem)
    • Numero de TVL requerido: n = log10(H_w/P)
    • Espesor: t = n * TVL (cm y mm)
    • Peso estimado (kg) para 10 m2
  8. Nota: Para doble haz (fotones + neutrones), calcule ambos por separado y sume espesores.
  9. Referencia: NCRP 151 Table B.7, McGinley (1998) Shielding Techniques.

19. Spatial Dose Map 2D — v108

Mapa de calor que visualiza la distribucion espacial de dosis alrededor de las fuentes, considerando atenuacion por barreras.

  1. Requiere al menos una fuente en el canvas.
  2. Haga clic en Map (icono Crosshair, color rojo) en el toolbar o sidebar.
  3. El sistema calcula la dosis en una grilla de 80x60 celdas sobre el area del canvas.
  4. Para cada celda:
    • Suma la contribucion de cada fuente: D = A*Gamma*h/(d^2)
    • Aplica atenuacion por cada barrera intersectada: D *= exp(-mu*t)
  5. El resultado se visualiza como heatmap:
    • Azul: Baja dosis (< 20% del maximo)
    • Amarillo: Media dosis (20-80%)
    • Rojo: Alta dosis (> 80%)
  6. Las barreras del canvas se dibujan como lineas negras sobre el mapa.
  7. Las fuentes se marcan como puntos blancos con borde negro.
  8. La leyenda inferior muestra la escala de colores y el valor maximo en uSv/semana.
  9. El limite publico (0.02 mSv/sem = 20 uSv/sem) se indica como referencia.
  10. El mapa es puramente informativo; no afecta los calculos NCRP.

Apendice A. Glosario de Terminos

TerminoDefinicion
AtenuacionReduccion de la intensidad de la radiacion al atravesar un material. Se expresa mediante el coeficiente μ (cm^-1).
Barrera PrimariaEstructura de blindaje que recibe el haz util directo de la fuente de radiacion. Calculada segun NCRP 147, ecuacion B = Pd^2/(WUT) para radiologia diagnostica.
Barrera SecundariaEstructura de blindaje que recibe unicamente radiacion dispersa (scatter) y fugada (leakage). Se calcula separadamente y se suma por metodo del arco.
Coeficiente de Ocupacion (T)Fraccion del tiempo durante el cual una zona puede estar ocupada mientras el haz esta dirigido hacia la barrera. Tabla A.1 NCRP 147 define 12 perfiles.
Factor de Uso (U)Fraccion del tiempo de trabajo durante el cual el haz util esta dirigido hacia una barrera especifica. Tipico: U=1 paredes laterales, U=1/4 paredes cruzadas, U=1/16 techo.
Capa de Valor Tenth (TVL)Espesor de material necesario para reducir la intensidad de radiacion a 1/10 (un decimo) de su valor original. NCRP 147/151 proporcionan TVL para multiples materiales y energias.
HVL (Half-Value Layer)Espesor de material necesario para reducir la intensidad a la mitad. HVL = ln(2)/μ ≈ 0.693/μ.
Dosis Equivalente (H)Cantidad obtenida multiplicando la dosis absorbida por el factor de peso radiacion wR. Unidad: Sievert (Sv). 1 mSv = 0.001 Sv.
Dosis Efectiva (E)Suma de las dosis equivalentes en los organos ponderadas por el factor de tejido wT. Representa el riesgo total de efectos estocasticos.
Tasa de Dosis (DR)Dosis por unidad de tiempo, tipicamente μSv/h o mSv/h. En RadShield se usa μSv/semana como unidad de diseno.
Meta de Dosis de Diseno (P)Tasa de dosis maxima permisible en una zona ocupada. Tipica: P=0.1 mSv/semana para areas publicas, P=0.02 para areas controladas.
Radiacion Dispersa (Scatter)Radiacion que cambia de direccion por interaccion con el paciente o material. NCRP 147: Is = (a W) / (d_scra^2 d_sec^2).
Radiacion de Fuga (Leakage)Radiacion que escapa del cabezal del equipo sin pasar por el colimador. NCRP 151 limita a 0.1% de la carga util para aceleradores.
SkyshineRadiacion que se dispersa en la atmosfera despues de atravesar el techo, irradiando zonas exteriores. NCRP 151 ecuacion: B_sky = 2.5×10^6 (W U T)/(P d_sky^2 (1+0.02θ)).
Monte Carlo (MC)Metodo estadistico que simula trayectorias individuales de particulas mediante muestreo aleatorio de secciones transversales. Geant4 es el "gold standard".
Red Neuronal Artificial (ANN)Modelo computacional inspirado en las redes neuronales biologicas. RadShield usa [6→64→32→16→1] para prediccion de espesores de blindaje.
ONNX (Open Neural Network Exchange)Formato abierto para representar modelos de ML. Permite ejecutar modelos entrenados en PyTorch/TensorFlow en cualquier runtime.
IFC (Industry Foundation Classes)Estandar ISO 16739 para intercambio de datos BIM entre aplicaciones. RadShield parsea IFC2X3 e IFC4.
BIM (Building Information Modeling)Metodologia de gestion de informacion de construccion en formato digital 3D. Revit es la plataforma lider.
SSR-6Reglamentos de la OIEA para el transporte seguro de materiales radiactivos. Base de NOM-013-NUCL-2013.
Indice de Seguridad (TI)A=T1+T2+T3, suma de los numeros de transporte de todos los radionucleidos presentes. Determina la categoria de envio.
QSA (Quality Assurance)Programa de garantia de calidad que incluye verificacion periodica de blindajes, calibracion de equipos y auditorias dosimetricas.

F.3. Pipeline de OpenCV.js

La deteccion automatica de muros mediante OpenCV.js sigue el siguiente pipeline:

  1. Carga de imagen: El usuario carga una imagen JPG/PNG del plano arquitectonico.
  2. Escala de grises: cv.cvtColor(src, gray, cv.COLOR_RGBA2GRAY).
  3. Desenfoque gaussiano: cv.GaussianBlur(gray, blurred, ksize={7,7}, sigma=2.0).
  4. Deteccion de bordes Canny: cv.Canny(blurred, edges, threshold1=50, threshold2=150).
  5. Transformada Hough probabilistica: cv.HoughLinesP(edges, lines, rho=1, theta=π/180, threshold=80, minLineLength=100, maxLineGap=10).
  6. Deteccion de contornos: cv.findContours(edges, contours, hierarchy, cv.RETR_EXTERNAL, cv.CHAIN_APPROX_SIMPLE).
  7. Filtro de lineas largas: Se filtran lineas con longitud > L_min (proporcional al tamano de imagen).
  8. Convercion a barreras: Cada linea detectada se convierte en un objeto Barrier con posicion, angulo y longitud estimada.
  9. Renderizado: Las barreras se dibujan sobre el canvas como elementos editables.

F.4. Pipeline de Machine Learning ONNX

El predictor ML (v101) utiliza el siguiente flujo de inferencia:

  1. Input features [6]: [energy_kVp, workload_mAmin, distance_m, occupancy_T, useFactor_U, materialIndex].
  2. Normalizacion: MinMax scaling a [0,1] usando parametros del entrenamiento.
  3. Inferencia ONNX: Session run con onnxruntime-web (WebAssembly backend).
  4. Arquitectura: Linear(6→64) → ReLU → Linear(64→32) → ReLU → Linear(32→16) → ReLU → Linear(16→1) → Sigmoid.
  5. Denormalizacion: output × (max_thickness - min_thickness) + min_thickness.
  6. Output: Espesor estimado en mm para el material seleccionado.
Nota sobre el modelo ONNX: La version actual (v101-v110) utiliza un modelo ONNX simulado con valores de fallback realistas basados en tablas NCRP. El entrenamiento completo requiere un dataset sintetico de ~10,000 casos generados mediante simulacion MC (Geant4/GATE) o interpolacion de tablas NCRP 147/151. Ver PYTHON_INTEGRATION_ROADMAP.md para instrucciones de entrenamiento con PyTorch.
